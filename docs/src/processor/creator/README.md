# Creators

A creator runs a build or install step anchored on a file (such as
`Cargo.toml` or `package.json`) and caches the directories and files it
declares as outputs. See [Processor Types](../../processor-types.md#creator) for
how creators work.

The pages in this section document the built-in creators.

Run `rsconstruct processor list` for the full list with each processor's type.
