# Generators

A generator transforms each input file into one or more output files whose
paths are derived from the input path. Outputs are cached as blobs and restored
when inputs are unchanged. See [Processor Types](../../processor-types.md#generator)
for how generators work.

The pages in this section document the built-in generators. These generators
have no dedicated page yet: ipdfunite, isass.

Run `rsconstruct processors list` for the full list with each processor's type.
